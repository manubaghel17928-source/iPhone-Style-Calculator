# iPhone Style Calculator

A simple and responsive iPhone-style calculator built using HTML, CSS and JavaScript.

## Features
- iPhone-inspired user interface
- Basic mathematical operations
- Clear and delete functionality
- Responsive design
- Interactive buttons

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
